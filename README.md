# MAB assessment results dashboard (anonymised)

Montessori Academy of Broward: MAP Growth, Stanford 10 and IXL results in one dashboard.
Students and guides appear as codes only (for example "Student S-4821", "Guide A").

## Publish with GitHub Pages
1. Upload `index.html` and `.nojekyll` to the root of this repository.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, folder **/ (root)** → Save.
3. After a minute or two the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Updating
Replace `index.html` with a newly exported file. The link stays the same.
